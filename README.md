# Jogo da Caverna

Jogo em FastBasic para Atari 8-bit.

## Controles

- Setas: mover
- SHIFT: atirar
- P: pause

## Objetivo

Colete moedas e destrua inimigos para alcançar 5000 pontos.

## Autor

Davidson de Oliveira Lima
